# Milestone 3: Database & Data Schema Design

## 1. Core Data Models

### 1.1 Weather Assessments (`weather_assessments`)
- `id` (string, primary key)
- `corridor_key` (string, indexed, e.g. "MAA-SGSIN")
- `wave_height_meters` (float)
- `wind_knots` (float)
- `beaufort_scale` (string)
- `storm_risk_score` (integer, 0-100)
- `delay_probability_pct` (float, 0-100)
- `buffer_hours` (integer)
- `updated_at` (timestamp)

### 1.2 Customs Compliance Checks (`customs_compliance_checks`)
- `id` (string, primary key, e.g. "CC-2026-001")
- `hs_code` (string, indexed)
- `origin_port` (string)
- `destination_port` (string)
- `incoterm` (string)
- `bcd_pct` (float)
- `igst_pct` (float)
- `sws_pct` (float)
- `status` (`CLEARED` | `NEEDS_REVIEW` | `NEEDS_DOCUMENTS` | `REJECTED`)
- `officer_sign_off` (boolean)
- `officer_notes` (text)
- `signed_off_by` (string)
- `signed_off_at` (timestamp)

### 1.3 Shipment Risk Evaluations (`shipment_risk_evaluations`)
- `id` (string, primary key)
- `shipment_id` (string, foreign key)
- `composite_score` (integer, 0-100)
- `risk_level` (`LOW` | `MEDIUM` | `HIGH` | `CRITICAL`)
- `weather_score` (integer)
- `customs_score` (integer)
- `route_score` (integer)
- `congestion_score` (integer)
- `cargo_score` (integer)
- `factors` (jsonb array)
